# Product Vision

## Name

Cordell

## Purpose

Cordell is a system for managing custody, checkout, and return of assets assigned to personnel designed for extreme clarity and practicality.

## Problem

The current process is based on physical paperwork, which makes it harder to search records, track current custody, inspect history, and maintain reliable operational visibility.

## Goal

Provide a clear, reliable, auditable, and maintainable system to register asset checkouts, returns, current custody balances, and custody history.

## Initial Scope

- Register personnel
- Register assets
- Register asset checkouts
- Register asset returns
- View current custody by personnel
- View custody history by personnel
- View current holders by asset

## Out of Scope for the First Version

- Digital signatures
- External integrations
- Mobile app
- Advanced reporting
- Offline synchronization

## Core Principles

- Correctness
- Auditability
- Maintainability
- Security
- Simplicity
- Explicit domain modeling
